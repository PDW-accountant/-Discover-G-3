# scripts/input — 변환 원본

`node scripts/convert.js`가 이 폴더의 파일을 읽어 `data/*.json`을 만듭니다(FUNC-016, #14).
원본을 바꾸면 변환을 다시 실행하세요. `data/*.json`은 손으로 고치지 않습니다.

- 라이선스: 서울 열린데이터광장 자료는 공공누리 제1유형(출처 표시), 공공데이터포털 자료는 이용허락범위 제한 없음.
- 공공데이터포털 15098252의 첨부 파일 링크에는 데이터가 아닌 이미지가 잘못 올라가 있습니다(2026-10-04 확인). 최신판 CSV는 담당자가 따로 받아 넣었습니다.
- `timetable-*.json`은 가상 데이터가 아니라 실제 열차 시간표에서 계산한 값입니다. 만드는 도구와 방법은 `scripts/timetable/`(각 파일 맨 위 주석)에 있습니다.
  ```
  node scripts/timetable/collect-seoul.cjs && node scripts/timetable/build-seoul.cjs
  node scripts/timetable/collect-tago.cjs  && node scripts/timetable/build-tago.cjs
  ```
  API 키는 `.env.local`(git에 올라가지 않음)에 `SEOUL_API_KEY=…`, `DATA_GO_KR_KEY=…`로 넣습니다. 받은 원본 시간표(약 115MB)는 `scripts/timetable/raw/`에 저장되고 git에는 올리지 않습니다.
- 검증: 시간표 추정값을 공식 값(1~8호선)과 비교하면 서울 시간표는 99%, TAGO는 98%가 30초 이내로 일치합니다.

## 콘텐츠팀 시트

| 파일 | 시트 탭 | 열 (이름·순서를 바꾸지 않는다) |
|---|---|---|
| `sheet-stations.csv` | 역 | `id, 역 이름, 호선, 권역, 메모` |
| `sheet-categories.csv` | 카테고리 | `역 id, 회식/식사, 회의/스터디, 오락/게임` (해당하면 O) |
| `sheet-places.csv` | 장소 | `역 id, 모임 종류, 가게 이름, 지도 링크, 한 줄 추천 이유, …` |
| `sheet-demo.csv` | 시연 시나리오 | `id, 이름, 모임 종류, 도착 시각(HH:MM), 참여자("닉네임:역 이름"을 쉼표로), 기대 1위 역, 기대 점수, 기대 단축 분` |

- 지금 파일은 콘텐츠팀 시트 10/6판(`모이자_역_카테고리_초안 (1).xlsx`)에서 내보낸 것입니다. 역 25곳(10/6에 서울역·신림·공덕·디지털미디어시티·고속터미널 추가, #77), 장소 164곳(후보 역·목적마다 3곳, 디지털미디어시티 회식만 2곳. 세부 정보 열은 아직 빈 칸). 시트가 바뀌면 각 탭을 CSV로 내려받아 같은 이름으로 바꿔 넣고 변환을 다시 실행하세요. 엑셀 숫자 칸(`5.0`)은 `5`로, 끝의 빈 행은 빼고 넣습니다.
- 카테고리 탭 아래쪽에 있던 작성자 이름 행은 데이터가 아니라서 넣지 않았습니다(실명은 저장소에 넣지 않는다).
- `sheet-demo.csv`는 개발팀이 지금 데이터로 직접 만든 시연 시나리오 3개입니다(10/4: 종로3가 회식 4명, 강남 회의 3명, 홍대입구 오락 5명). 기대 1위 역·점수·단축 분은 손으로 계산해 적고, `npm test`가 실제 계산 결과와 같은지 확인합니다.

## 역 이름 보정 (`scripts/aliases.json`)

자료마다 역 이름이 다를 때(옛 이름, 괄호 표기 등) 공식 이름으로 맞추는 표와, 서울 경계 사각형 안이지만 서울시가 아닌 역 목록입니다. 변환 결과에 "역 이름 불일치"가 나오면 여기에 추가합니다.
