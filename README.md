## 내려받아 실행하기

빌드·설치가 필요 없습니다. 화면은 HTML·CSS·JavaScript 파일 그대로이고, 이동시간은 `data/`의 공공데이터로 브라우저가 직접 계산합니다.

```bash
git clone https://github.com/PDW-accountant/-Discover-G-3.git
cd ./-Discover-G-3
python -m http.server 8000      # 또는 VS Code의 Live Server 확장으로 index.html 열기
```

브라우저에서 **http://localhost:8000** 을 엽니다. 휴대폰 크기로 보려면 개발자 도구(F12) → 기기 모드 → 가로 375.

- `index.html`을 **더블클릭(file://)으로 열면 동작하지 않습니다.** 브라우저가 파일 주소에서는 모듈과 `data/*.json` 읽기를 막기 때문입니다. 위처럼 간이 웹서버로 열어 주세요(Python 3 또는 Live Server).
- 바로 결과를 보려면 첫 화면 아래 **[예시로 해보기]** 시나리오 버튼을 누르세요(종로3가 회식·강남 회의·홍대입구 오락).

### 서버(모임 방) 없이 실행할 때

이렇게 내려받아 열면 Vercel 서버 함수와 Upstash Redis(모임 방 저장소)가 없습니다. 앱은 이를 알아채고 **방 기능만 끄고** 나머지는 그대로 동작합니다.

| 기능 | 서버 없이 |
|---|---|
| 모임 조건 입력, 출발역 입력(총무가 모두 입력), 공평한 역 추천, 만남 장소, 약속 확정, 개인 경로, 뒤로가기 | 동작 |
| 확정 링크 공유(링크 복사) | 동작 — 확정 정보를 주소 `#d=…`에 담는 방식 |
| 임시저장·이어서 입력, 내 약속 목록 | 동작 — 브라우저 저장소(localStorage) 사용 |
| **[링크로 입력받기]**(참여자가 각자 링크로 입력하는 방 모드, 입력 현황) | **버튼이 숨겨짐** — 모임 방을 저장할 곳이 없음 |
| 카카오톡으로 보내기 | 동작하지 않음 — 카카오 JavaScript 키가 없으면 버튼이 숨겨지고, 키가 있어도 카카오에 등록한 도메인(배포 주소)에서만 열림. 링크 복사로 공유 |

방 모드까지 보려면 배포된 사이트(https://eodiga3.vercel.app)를 쓰거나, `.env.example`을 `.env.local`로 복사해 Upstash 값을 넣고 `npx vercel dev`(Vercel 로그인 필요)로 실행합니다.

## 협업 규칙

- `main`에 직접 push하지 않습니다. `feature/[이름]-[기능]` 브랜치에서 작업하고 PR로 합칩니다. 병합은 대원이 합니다.
- 브랜치를 push하면 1~2분 뒤 그 브랜치 전용 미리보기 주소가 생깁니다: `https://eodiga3-git-<브랜치명>-pw-c-discover-g-3.vercel.app` (브랜치 이름이 길면 주소가 줄어드니 PR의 Vercel 댓글에서 확인)
- 커밋 메시지: 한국어 한 줄 + `(#이슈번호)`. 예: `출발역 검색 목록에 호선 표시 추가 (#3)`
- `.env`, `.env.local`, 토큰은 커밋하지 않습니다 (`.gitignore`로 막혀 있음).
